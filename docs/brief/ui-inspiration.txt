Typography
Pairing
         * Display serif for headlines (high contrast, editorial feel). Likely something in the Canela / Baskerville / Georgia-ish family.
         * Modern sans for UI + body (neutral, readable). Likely Inter / Helvetica / SF Pro / system-ui style.
Sizing & rhythm (what the modal suggests)
         * H1 / hero headline: 44–56px, serif, tight-ish line-height (~1.05–1.15)
         * Subhead/section lead: 18–22px, sans, line-height 1.4–1.6
         * Body: 16–18px, sans, line-height 1.5–1.7
         * Legal/disclaimer: 12–13px, sans, line-height 1.4–1.6
Font-weight
         * Serif display: 400–500
         * Sans UI/body: 400, with 500–600 for button labels
Visual CSS guidelines (component rules)
Layout & spacing
         * Lots of breathing room: base spacing unit 8px
         * Modal padding: 32–40px
         * Section vertical spacing: 48–96px depending on density
         * Max content width (typical): 1120–1200px
Buttons
         * Primary: filled deep green, white text, rounded pill
         * Height: 48–56px
         * Padding: 14–18px vertical, 24–36px horizontal
         * Border radius: 999px (full pill)
         * Hover: darken background slightly
         * Active: tiny translate/press effect optional
Inputs
         * Rounded pill input with thin border
         * Height: 48–56px
         * Border: 1px solid var(--border-200)
         * Padding: 0 18–22px
         * Focus: subtle ring, not neon
Links
         * Underlined or subtle underline-on-hover in legal areas
         * Colour usually inherits ink/green; avoid bright link blue
Cards / surfaces
         * Background: warm off-white / white
         * Shadow: very soft (or none); emphasis comes from spacing
         * Corners: 16–24px on cards; 999px on pills
Imagery
         * photography is bright, natural, slightly warm
         * Use generous crops and minimal overlays
         * Avoid heavy gradients; keep UI crisp and clean
