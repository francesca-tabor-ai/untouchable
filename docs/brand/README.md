# Brand assets

The originals, as supplied. The versions the site actually uses are derived from these.

| File | What it is |
|---|---|
| `Logo.svg` | The supplied vector. **This is the master.** Copied to `public/logo.svg` unchanged. |
| `Logo.png` | The supplied raster. **Not used.** It is a trace of the same mark with visible speckling through the ring and square, and at 641KB it is 450 times the size of the SVG for a worse result. |

`src/app/icon.svg` is a simplified cut for the favicon: at 16px the full mark's concentric
ring and square collapse into a green smudge, so the icon keeps only the petals and a solid
triangle.

The mark is the Muladhara — the root chakra — a sacred symbol in Hindu and Buddhist practice.
Two things follow from that, neither of them engineering decisions:

- A traditional religious symbol is hard to register as a trade mark, because it is not
  distinctive to us and never has been. Brief section 12 lists trademark as an open question;
  this is part of the answer.
- Using it as the identity of a commercial health platform is a choice some people will read
  as appropriation. Worth deciding deliberately rather than by default.
